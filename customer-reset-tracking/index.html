Does a Reset Lift Sales?

Every 2026 shelf/cooler reset (the "SFS" program), compared against the same 90-day window one year earlier at that same account — controls for seasonality the same way the prior two program years' own methodology did. First-time resets (brand-new to the program) are tracked separately from repeat resets (reset again in 2024 and/or 2025), since combining them hides very different effects.

    Methodology & data notes

    Post window: each account's own Reset Date through Reset Date + 90 days, using 2026 transactions.

    Pre window: the same 90-day calendar window one year earlier (Reset Date − 365 days), using 2025 transactions — a year-over-year comparison, not a same-year before/after, so a reset's apparent effect isn't just normal seasonal variation.

    Lift %: (post total − pre total) / pre total, on Case Equivalents (the headline metric; $ Volume and Gross Profit are tracked the same way per account, see the export).
