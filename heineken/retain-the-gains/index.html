Kohler Distributing · Heineken USA · Retain the Gains tracker.
Source of truth: HUSA's official Retained-PODs export (ON PREMISE + OFF PREMISE), refreshed manually as HUSA sends new files. Rep attribution is matched against Kohler's own customer roster (address/city), since HUSA and Kohler use different outlet ID systems (VIP vs. Encompass) — outlets that couldn't be matched are grouped under “Unmatched — Needs Review” rather than guessed. Confirmed directly with a HUSA rep on 7/17: this file has no “successfully retained” state — every flagged cell is Unretained (a longstanding gap), a Lost New Gain (won in Mar–Apr, not yet regained in Jun–Aug — higher priority since it's a fresh loss), or an Open Opportunity (never filled in either period, not a loss at all). There's intentionally no retention-rate percentage on this page.
EP's / DB's come from HUSA's separate T2 Core Distribution exports (not the retained/unretained file above) — Off Premise (EP's) sums every SKU/format Total column per outlet (730, exact match to HUSA's T2 slide); On Premise (DB's) counts distinct outlets carrying at least one Heineken-family SKU, from a hierarchical Route→Account→Brand→Package export (655, exact match). Goal figures are fixed HUSA targets, not calculated from any file we have.
