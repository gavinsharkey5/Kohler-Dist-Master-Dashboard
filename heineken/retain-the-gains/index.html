Source of truth: HUSA's official Retained-PODs export (ON PREMISE + OFF PREMISE), refreshed manually as HUSA sends new files. Rep attribution is matched against Kohler's own customer roster (address/city), since HUSA and Kohler use different outlet ID systems (VIP vs. Encompass) — outlets that couldn't be matched are grouped under “Unmatched — Needs Review” rather than guessed. Retention rate = Retained ÷ (Retained + Unretained); New Placements are POD wins from the program window and aren't counted against the rate.
EP's / DB's come from a separate HUSA current-state POD export (not the retained/unretained file) — Off Premise (EP's) sums Large-format outlets only, which matched HUSA's reported 645 almost exactly (650); On Premise (DB's) sums all tracked outlets (382 vs. HUSA's 374). Goal figures are fixed HUSA targets, not calculated from any file we have.
